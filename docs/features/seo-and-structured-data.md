# SEO & Structured Data

Better Horizon generates structured JSON-LD data to maximize search visibility and Google Rich Snippets.

---

## 🚀 Supported Schemas

1. **Organization Schema:** Store name, logo, URLs, and social profile links on all pages.
2. **Product Schema:** Product title, images, description, brand, SKU, and variant offers (`price`, `priceCurrency`, `availability`).
3. **Collection Schema:** `ItemList` markup indexing category products.
4. **BreadcrumbList Schema:** Hierarchical breadcrumb navigation paths for Google indexing.
5. **SearchAction Sitelinks:** Enables Google Search Box sitelinks directly in search engine results.

---

## 📁 Files
- `snippets/structured-data.liquid` — JSON-LD generator template.
- `snippets/meta-tags.liquid` — OpenGraph and Twitter card metadata.
