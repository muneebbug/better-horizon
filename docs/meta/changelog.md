# Changelog

All notable changes to **Better Horizon** are documented in this file.

---

## [4.1.4-bh.1] - 2026-08-31

### Added
- **Wishlist System:** Slide-out drawer (`#wishlist-drawer`), header count bubble, and direct add-to-cart dispatch.
- **Quick View:** Modal product preview dialog and loading spinner on catalog Choose buttons.
- **Back in Stock:** Sold-out variant email capture block with automated customer tags.
- **Frequently Bought Together:** Multi-item bundle recommendations with real-time price summation.
- **Free Shipping Bar:** Dynamic cart drawer progress bar calculating remaining amount live against cart total.
- **Trust Badges Bar:** Store guarantee block with grid and horizontal layout modes.
- **Countdown Timer:** ISO date and metafield-driven urgency countdown block.
- **Dynamic Size Chart:** Sizing guide modal sourcing content dynamically from Shopify Pages or product metafields.
- **Geo Market Banner:** Regional country recommendation banner with single-click market switching.
- **RTL Support:** Native Right-to-Left bidirectional styling for Arabic, Hebrew, and Urdu.
- **SEO Schemas:** Automated JSON-LD structured data for Organization, Product, Collection, and Breadcrumbs.

### Changed
- Refined theme settings schema to follow native Horizon naming conventions.
- Harmonized all custom component borders, input fields, radii, and text colors with Horizon design tokens.
