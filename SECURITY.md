# Security Policy

## Supported Versions

We actively support and provide security updates for the following versions of Better Horizon:

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| < 4.0   | :x:                |

---

## Reporting a Vulnerability

The Better Horizon team takes the security of our open-source theme and merchant stores seriously.

If you discover a security vulnerability in Better Horizon:

1. **Do not create a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by contacting the maintainers directly through GitHub.
3. Include detailed reproduction steps, proof of concept, and affected files/versions.

We will acknowledge receipt within 48 hours and work with you to patch and disclose the fix responsibly.
